隐私政策

适用应用：yt-bridge　·　最后更新：2026 年 11 月 3 日

1. 这是什么

yt-bridge 是仅运行在开发者本人 Windows 电脑上的个人自动化脚本，用于整理本人 YouTube「稍后观看」列表中的视频并生成本地观看摘要，供本人筛选归档。它不对外开放注册，不提供在线服务，也未上架任何应用商店。

2. 访问哪些 Google 用户数据

仅在账号本人明确授权后，通过 Google OAuth 2.0 以只读权限访问：

  • 授权范围：https://www.googleapis.com/auth/youtube.readonly（只读）
  • 读取内容：本人 YouTube 账号「稍后观看」列表中的视频 ID、标题、频道名称、时长

不读取、不修改、不删除任何其他 YouTube 数据；不上传视频、不改动播放列表、不读取私信、评论或订阅信息。

3. 数据用途

仅用于在本人电脑上生成本地视频摘要清单，帮助本人决定是否下载归档。不用于广告、用户画像、转售或任何第三方用途。

4. 存储与保留

  • 所有数据仅保存在开发者本人的本地计算机（本地文本 / JSON 文件）。
  • 本工具没有服务端、没有云数据库，不上传任何数据到互联网。
  • OAuth 刷新令牌同样只存于本地，保存在仅当前系统用户可读的文件中。

5. 共享与转让

不与任何第三方共享、出售、出租或转让 Google 用户数据；不使用 Google 用户数据训练任何机器学习模型。

6. 撤销授权与删除数据

可随时访问 Google 账号权限页 撤销本应用访问权限。撤销后本工具立即无法读取任何数据；删除本地令牌与清单文件即完成全部清除。

7. 政策遵从

本工具对 Google API 所获数据的处理遵循 Google API Services User Data Policy，包括其中 Limited Use 要求。

8. 联系方式

通过 GitHub 联系：github.com/MuddywatersUS

Privacy Policy

App: yt-bridge　·　Last updated: November 3, 2026

1. What this is

yt-bridge is a personal automation script running only on the developer's own Windows computer. It organizes videos in the developer's own YouTube Watch Later list and produces a local summary for personal triage. It has no public sign-up, no online service, and is not distributed through any app store.

2. Google user data accessed

Only with the account owner's consent, and only read-only, the app accesses:

  • Scope: https://www.googleapis.com/auth/youtube.readonly
  • Data: video IDs, titles, channel names and durations from the owner's own Watch Later playlist

No other YouTube data is read, modified or deleted. The app does not upload videos, modify playlists, or read messages, comments or subscriptions.

3. How data is used

Solely to build a local summary on the owner's computer so the owner can decide whether to archive a video. No advertising, profiling, resale or third-party use.

4. Storage and retention

  • All data stays on the developer's local computer as local text/JSON files.
  • No server and no cloud database; nothing is uploaded.
  • The OAuth refresh token is stored only locally, readable only by the local OS user.

5. Sharing

Google user data is never shared, sold, rented or transferred to any third party, and is never used to train machine-learning models.

6. Revoking access and deleting data

Access can be revoked anytime at the Google Account permissions page. After revocation the app can no longer read any data; deleting the local token and summary files removes everything.

7. Compliance

Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
